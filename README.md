# Livsbalanse (PWA)

Statisk app – ingen server. Data lagres lokalt i nettleseren (bruk 💾 backup for å flytte mellom enheter).

## Legg ut gratis (GitHub Pages)
1. Lag et nytt repo på github.com, last opp alle filene i denne mappen.
2. Settings → Pages → Branch: `main` / root → Save.
3. Åpne `https://<brukernavn>.github.io/<repo>/`.

Alternativ: dra mappen inn på https://app.netlify.com/drop eller Cloudflare Pages.

## Installer på mobil
Åpne siden → Chrome: ⋮ → «Legg til på startskjermen» / Safari: Del → «Legg til på Hjem-skjerm».
